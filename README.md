# ABC Company Employee Analysis
This project analyzes employee data from ABC Company. The dataset contains 458 rows and 9 columns. The project includes data preprocessing, analysis, visualization, and insights.

**Preprocessing**
The height column contained inconsistent data and was replaced with random values between 150 and 180.

**Analysis Performed**
1. Employee distribution across teams
2. Employee distribution by position
3. Predominant age group
4. Highest salary expenditure by team and position
5. Correlation between age and salary

**Insights**
- Employees are mainly concentrated in certain teams.
- Most employees work in operational positions rather than managerial roles.
- Majority employees fall in the 30–39 age group.
- Highest salary expenditure comes from senior positions and certain teams.
- There is a positive correlation between age and salary.
